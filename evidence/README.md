# Supporting historical evidence

This folder contains selected, redacted historical development captures. It is intentionally supplementary to the reproducible synthetic tests and diagrams in `assets/`.

Every image here was prepared from a private development archive using opaque redaction or cropping. The public copies exclude local paths, broker/server/account information, configuration values, prices, position sizes, entry/exit details and proprietary decision criteria.

| File | Demonstrates |
| --- | --- |
| `historical-research-report.jpg` | Aggregate research reporting: trade count, expectancy and drawdown. |
| `historical-multi-instrument-organisation.jpg` | Instrument-scoped code/data/configuration organisation. |
| `historical-mt5-automated-run.jpg` | A development-time automated MT5 run harness. |
| `historical-mt5-deal-history.jpg` | An anonymised MT5 deal-history view showing selected automated-development outcomes. |
| `historical-ai-execution-design.jpg` | AI-assisted discussion of a multi-terminal execution abstraction. |

Historical result captures are implementation evidence only. They are not investment advice, performance guarantees or a basis for reproducing the private strategy.
