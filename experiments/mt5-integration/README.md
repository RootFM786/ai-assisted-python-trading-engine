# Later MT5 integration experiment

This folder is a **later experimental branch** preserved to demonstrate broker/API integration work. It is not part of the locked XAUUSD V1 engine and should not be read as the final V1 architecture.

Included artifacts show:

- MetaTrader 5 connectivity/wrapper code
- rate retrieval and normalization
- position-sizing logic
- a connectivity smoke test
- credential-free example configuration files

The original archive also contains additional live/demo runners and strategy experiments. Those are deliberately omitted here to keep the portfolio repository focused and to avoid implying production or live-money deployment.

No broker login, password, account number or API secret is included.
